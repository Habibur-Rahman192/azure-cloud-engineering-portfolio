\# ⭐ Featured Project



\## 🔐 Implement RBAC with Microsoft Entra ID



\### Overview



This project demonstrates the implementation of Azure Role-Based Access Control (RBAC) using Microsoft Entra ID security groups to manage permissions securely and enforce the principle of least privilege.



\### Key Outcomes



✅ Created and managed security groups



✅ Assigned Reader permissions through Azure RBAC



✅ Validated user access and permission boundaries



✅ Tested administrative restrictions



✅ Verified access revocation after role removal
