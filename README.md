\## Featured Project



\### Implement RBAC with Microsoft Entra ID



A practical demonstration of Azure Role-Based Access Control (RBAC) using Microsoft Entra ID.



\*\*Key Outcomes\*\*

\- Created and managed security groups.

\- Assigned Reader permissions to users through group membership.

\- Validated read-only access to Azure resources.

\- Confirmed permission restrictions when performing administrative actions.

\- Removed role assignments and verified immediate access revocation.



\*\*Skills Demonstrated\*\*

\- Microsoft Entra ID

\- Azure RBAC

\- Identity \& Access Management

\- Security Groups

\- Least Privilege Access
